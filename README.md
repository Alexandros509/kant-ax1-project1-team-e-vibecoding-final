# ONEPIECE · Vibe Coding Final

팀 쇼핑몰 프로젝트의 바이브코딩 최종 정리본입니다. **가상 상품으로 쇼핑 UI와 구매 여정·GA4 측정을 연습하는 교육용 데모**이며 실제 판매·배송·과금 서비스가 아닙니다.

원본: [kant-ax1-project1-team-e](https://github.com/Alexandros509/kant-ax1-project1-team-e).
기존 팀 저장소는 유지하고, 배포 파일만 선별한 새 이력으로 구성했습니다. 팀 기여를 단독 제작물로 주장하지 않습니다.

## 공개 범위와 권리

- 공개 저장소라고 모든 코드에 오픈소스 재배포 권한이 생기는 것은 아닙니다. 기존 팀 코드에 새 라이선스를 임의로 부여하지 않았습니다. [RIGHTS.md](RIGHTS.md)를 먼저 읽어주세요.
- 학습·비영리·클론 테스트 목적이라는 문구는 저작권·상표권 허가나 법적 면책이 아닙니다. 권리 침해가 전혀 없다고 보증하지 않습니다.
- 참고 쇼핑몰의 상품 사진·영상·로고·수집 상세 설명·원문 JSON/HTML·화면 캡처는 제외했습니다. CDN 링크도 대체 수단으로 남기지 않았습니다.
- 대신 새로 만든 SVG 의류 일러스트와 **12개 스타일 / 36개 색상 카드 / 126개 옵션 / 108개 이미지**를 제공합니다. 가격·사이즈·재고도 가상입니다. 원본 로컬 사이트의 실제 수집 카탈로그·영상과 화면이 다를 수 있습니다.
- ONEPIECE는 이 실습의 가상 명칭입니다. SAN SAN GEAR, 동명 프랜차이즈, Kakao, Toss Payments와 제휴·공식 관계가 없습니다.
- 라이브러리 라이선스는 각각 유지됩니다. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 참고하세요.

## 실행

Node.js 22 이상, npm을 사용합니다. 한 DB 폴더를 여러 서버 프로세스에서 동시에 열지 마세요.

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev -- --hostname 127.0.0.1 --port 3019
```

[http://127.0.0.1:3019](http://127.0.0.1:3019)에서 확인합니다. 기본 상태는 키 없이 목록·상세·관심/최근 상품·장바구니를 볼 수 있고, 로그인과 테스트 결제는 설정 전 비활성화됩니다. 우회 로그인이나 실제 결제 대체 기능은 없습니다.

```powershell
npm test
npm run lint
npm run release:check
npm run build
npm run start -- --hostname 127.0.0.1 --port 3019
```

## 구현 범위

- 하단 고정 내비게이션, 카테고리 목록, 가격 정렬, 3·4·6열 표시 및 품절 필터.
- 상세 큰 이미지 한 장과 좌우 이동·썸네일 레일, 사이즈 선택, 상세·관리·배송 안내.
- 히어로의 의류 영역에서 데모 상세로 이동. 공개본은 원본 캠페인 영상 대신 새 SVG를 사용합니다.
- 관심 상품과 최근 본 상품은 브라우저 저장소에 보관합니다. `You may also like` 영역은 관심 목록이며 AI 추천이 아닙니다.
- 비회원 장바구니 → Kakao 로그인 시 회원 장바구니 연결, 주문 금액 서버 검증과 주문 시점 스냅샷.
- Kakao OAuth state 검증·일회 사용, 세션 교체. Toss 테스트 결제 준비·승인·재시도 멱등성·소유자 검증·결제 상태 조회 및 환불 내역 동기화.
- 외부 키와 실제 계정 없이 동작하는 OAuth/결제 모의 테스트를 포함합니다. 실제 제공자 성공 결제 검증은 별도 테스트 키와 앱 설정이 필요합니다.

실제 배송, 운영 결제, 관리자 운영 도구, 쿠폰·포인트·등급, 자동 추천, 취소 실행 API/웹훅은 구현 범위에 포함하지 않습니다. 페이지가 존재한다는 이유로 해당 기능을 구현했다고 보지 마세요.

## DB와 ERD

PGlite로 로컬 PostgreSQL을 실행합니다. 최초 서버 API 요청 시 `.local/onepiece-db`에 스키마와 합성 카탈로그만 생성합니다. 사용자·주문·결제 기본 행은 없습니다.

- 기준: [선택 ERD](https://www.erdcloud.com/d/hE52as4HR9aAepZTt). 공유 ERD는 수정하지 않았습니다.
- **26개 테이블 / 159개 컬럼 / 31개 외래 키**. `db/erdcloud-source.sql`은 기준 구조, `db/schema.sql`은 PostgreSQL 문법에 맞춘 실행 스키마입니다.
- ERD 밖의 visitors / experiments / user_events / auth / sessions 테이블을 추가하지 않았습니다.
- 세션·OAuth state·동의·이벤트 중복 억제는 서버 메모리에 있어 재시작하면 초기화됩니다. 회원·주문 데이터는 DB에 남습니다. 다중 서버 운영용 세션 저장소가 아닙니다.
- 재고는 합성 가용성 데이터입니다. 주문으로 실물 재고를 예약·차감하는 운영 정책을 제공하지 않습니다.
- `supabase/migrations/`와 `supabase/seed.sql`은 구조와 합성 카탈로그입니다. 클라우드 연결·Auth 매핑·RLS·운영 정책은 별도 작업이며 이 SQL을 공용 브라우저 DB로 바로 노출하면 안 됩니다.

서버를 멈추고 외부 백업을 만든 뒤에만 초기화합니다. 아래 명령은 이 저장소의 로컬 DB 데이터를 삭제하고 합성 fixture로 재생성합니다.

```powershell
npm run db:reset -- --confirm-local-reset
```

`npm run db:erd`는 스키마, `npm run db:audit`는 테이블·행 수만 출력합니다. `db:export`는 이름이 카탈로그 전용이어도 DB 안의 콘텐츠를 내보내므로 권리 확인 전 커밋하지 마세요. 실행 중인 서버와 같은 DB를 동시에 열지 마세요.

## GA4와 A/B 테스트

`.env.local`의 `NEXT_PUBLIC_GA_MEASUREMENT_ID`를 팀의 **테스트 전용 GA4 속성**으로 설정합니다. 빈 값이면 GA 스크립트를 불러오지 않습니다. 동의 후 목록·선택·상세·장바구니·체크아웃 이벤트와 테스트 승인 후 purchase를 전송하는 경로가 있습니다. 개인 주소·전화번호·로그인 식별자를 GA에 보내지 마세요.

**현재 기본 화면은 개선 UI 한 벌입니다.** A/B 자동 무작위 배정·고정 배정·표본 계산·결과 대시보드를 완성한 실험 플랫폼은 아닙니다. `?preview=A/B`는 화면 검토용이며 분석에서 제외됩니다. 팀이 실제 대조안을 만들고 배정·노출 기록·GA4 사용자 정의 차원·실험 종료 기준을 설정해야 합니다.

A/B 두 조건에는 동일 fixture 버전, 카테고리, 상품 옵션·가격·가용성과 시작 재고를 사용하세요. 공개본 합성 카탈로그와 기존 로컬 수집 카탈로그를 서로 비교하면 UI만의 효과를 분리할 수 없습니다. 테스트 purchase는 실제 매출이 아닙니다.

## 백업과 공개 전 검사

실제 DB 및 이전 소스·미디어 백업은 이 저장소 밖 로컬 폴더에만 보관합니다. 저장소에는 [backups/README.md](backups/README.md) 안내만 있습니다. Git LFS·Release·Actions artifact도 백업 업로드 수단으로 사용하지 않습니다.

`npm run release:check`는 Git 추적 파일의 금지 경로·미디어·DB·키 패턴·외부 상품 이미지 참조와 원본 데모 자산 해시를 검사합니다. 자동 검사는 보조 장치이며 모든 권리 문제나 모든 종류의 비밀을 판정하지 못합니다. 향후 파일을 추가할 때마다 출처와 권한을 따로 확인하세요.

검증 결과와 개발 도구의 알려진 취약점 제한은 [docs/VERIFICATION.md](docs/VERIFICATION.md)에 구분해 기록했습니다.

구성: `src/` 앱, `data/` 합성 fixture, `public/demo/` 새 SVG, `db/` ERD 스키마, `supabase/` SQL, `scripts/` 로컬 도구, `docs/` 설정·검증 안내.
