# Synthetic catalog
This fixture was created for this publication snapshot. It contains no crawled product records.
There are 12 generic styles, 36 color cards, 126 options and 108 image references.
All prices, sizes, specifications and availability are fictional. Images are local original SVG illustrations.
The schema groups color cards under styles. Numeric route IDs are stable only for this fixture version.
For an A/B comparison, use this exact fixture and the same starting inventory in both arms.
Do not mix this fixture with the private local crawl or reuse numeric cart IDs across fixture versions.
